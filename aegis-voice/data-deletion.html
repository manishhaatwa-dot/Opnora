Data Deletion Instructions

1. About Data Deletion

Aegis Voice provides an in-app Data Deletion feature that allows users to remove supported information stored locally by the application on their device.

Users do not need to contact the developer to use this in-app local data deletion feature.

2. How to Delete Your Data

Follow these steps inside the Aegis Voice application:

  1. Open the Aegis Voice application.
  2. Scroll to the bottom of the main screen.
  3. Tap the Data Deletion option.
  4. Review the information about data deletion.
  5. Tap Delete All Local Data.
  6. Read the confirmation message carefully.
  7. Tap Yes, Delete to confirm.

The application will stop voice monitoring before starting the supported local deletion process. If an emergency SOS operation is active, deletion is blocked until the SOS operation finishes.

3. Information Deleted by the Feature

The in-app Data Deletion feature is designed to remove:

  • Saved emergency contact information.
  • Saved voice trigger phrases.
  • Associated voice recordings covered by the deletion feature.
  • Cached GPS location information.
  • The locally copied voice model file (bpe.model).

4. Important Information

The Data Deletion feature removes supported local application data. It does not delete:

  • SMS messages already sent to emergency contacts.
  • Phone call history.
  • Android permissions granted to the application.
  • Information stored outside the application's local storage.
  • Files or information stored independently by other applications.

Deletion is permanent for the supported data successfully removed by the feature and cannot be undone.

5. Deletion Errors

If the application cannot stop voice monitoring or encounters an error while deleting local data, it may cancel or report an incomplete deletion.

If deletion does not complete, try again after voice monitoring has stopped and any active emergency SOS operation has finished.
